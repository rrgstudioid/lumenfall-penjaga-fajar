HASIL IMPLEMENTASI
- meteorfall-citadel-population.ts: 36 normal lama tetap dengan ID, species dan posisi
  semula. Tambahan 180 memakai ID 200–379. Setiap hunting island memiliki 36 normal;
  anchors deterministik menghindari void, obstacle, magma terbuka dan bridge docking.
  Elite 90–94 dan boss 100 tetap; format respawn key/timer tidak diubah.
- meteorfall-citadel-materials.ts / map.ts: shared road material dengan jaringan retakan
  magma lebih rapat, emission lebih terang dan pulse lambat; dipakai bridge/causeway dan
  pendekatan jalan. Pijakan tetap basalt walkable dengan collision yang sama.
- meteorfall-citadel-footprints.ts: jejak kaki kiri/kanan berbasis jarak 0.85 unit, mengikuti
  ground/ramp, membara lalu mendingin dan hilang dalam 6 detik. Pool maksimal 128 dalam
  satu InstancedMesh, tanpa tekstur/lampu/damage tambahan. Tidak muncul saat idle,
  teleport, pause atau di void. Resource ikut dilepas pada disposal map.
- Dragon Veil Head, Armor, Legs, Boots: model Male V2, empat LOD per bagian, ikon asli,
  data item/stats terdahulu dan pembelian 0 GOLD di Developer Material Lab dipulihkan.
  Aset runtime dipulihkan byte-for-byte dari b229218: 16 GLB + provenance manifest
  (15,055,295 bytes), ditambah empat ikon WebP. Source library/.blend tidak diubah.
- Alias Dragon Veil Pants tetap menuju Legs, termasuk model/ikon pada item lama.
  Owned instance ID, enhancement dan rune tetap. Keempat armor hanya untuk male;
  tidak muncul sebagai normal loot dan tidak memiliki set bonus tambahan.
- Gloves dihapus dari EquipSlot, empty loadout, Character UI, attachment dan toko.
  Item Gloves lama tetap bisa dibaca/dimiliki, tidak dapat dipakai, dan tidak memberi
  stats aktif. Migrasi melepaskannya; jika bag penuh, instance masuk pendingLoot tanpa
  kehilangan enhancement/rune. Migrasi reload berikutnya idempotent.
- Readiness/error/retry model Dragon Veil kembali aktif; ikon independen tetap disimpan
  oleh extract-item-icons.py agar regenerasi sheet tidak menghapus mapping tersebut.
- Wings, formula combat, skill definitions, accuracy-evasion-fixture.ts, dan source
  aset asli tidak diubah. Perubahan sebelumnya di working tree tetap dipertahankan.
