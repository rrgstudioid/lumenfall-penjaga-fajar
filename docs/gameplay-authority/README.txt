LUMENFALL — DURABLE SELECTED AUTHORITY COPIES

These files preserve the selected design evidence needed to review the integrated
runtime. They are not a new OWNER_ACC, a complete conversation archive, or a claim
that every historical value is current. Original sources remain untouched.

PROVENANCE.json maps every exact copy to its original path, original SHA256,
status and approval boundary. The Warrior oracle lives at
tests/fixtures/warrior-final-input-package.json and is byte-identical to the
historical package; tests read this durable copy, not ignored checkpoint output.
Do not regenerate expected values from the producer under test.

Read later approvals together with the earlier proposals they qualify. Preserve
PROPOSED/HOLD labels in originals. Filenames and assistant LOCK labels do not
establish OWNER approval. Historical references to attachments/outputs are source
provenance; this package deliberately does not copy all linked archives.

INTEGRATION_CONSTRAINTS.txt summarizes later corrections and current scope. Only
the exact explicit approvals recorded in the paired sources have design authority.
Copying this package does not enable development routes or authorize Git/publish.
